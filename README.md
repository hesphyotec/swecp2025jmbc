HOW TO USE
    -Download Docker
    -Download recipe-app/src/FullApp from main
    -Navigate to that directory in your terminal
    -In your terminal, write "Docker compose up --build"
    -Every time after, just run "Docker compose up"
            *WARNING* if you use --build after your first time, your db data will be lost,
            only build again if you use proper tags!
